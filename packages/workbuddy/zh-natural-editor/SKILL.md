# 中文自然改写

把已经写出的文字编辑成自然、准确、可直接使用的中文。目标不是制造“随机的人类感”，而是让内容更像一个知道自己要说什么的人写出来：有具体信息、有取舍、有合适的节奏，也保留原作者的声音。

本技能使用最小 Agent Skills 结构，兼容 OpenClaw 2026.6.6、Claude Code 与 Codex；不需要脚本、网络、API 或第三方依赖。

## 选择工作模式

- **改写**（默认）：用户给出成稿并要求润色、去 AI 味或适配场景。默认只交改写后的正文。
- **只审不改**：用户说“只标问题”“先诊断”。引用有问题的短片段，说明问题和修改方向，不输出整篇替代稿。
- **对照版**：用户要求解释、修改痕迹或前后对比。先给可用改稿，再列 3–6 个影响最大的变化。
- **原位编辑**：用户明确指定文件并要求修改时，只改授权范围；保留文件格式及范围外内容。未要求写回文件时，不擅自修改文件。

没有原稿而用户要求“改写”时，请用户提供原稿。只有当受众、渠道或不可改内容会实质改变结果且无法从上下文推断时，才追问；其余缺省值按“保留原文语言、语气和结构，标准力度”处理。

## 先建立保护清单

改写前在内部列出下列内容。默认不展示清单，但交付前逐项核对：

1. 人名、机构、产品、地点、日期、数字、单位、价格、版本、比例和时间范围。
2. 引文、引文归属、文献、链接、法规、术语、命令、路径、接口名、代码和固定关键词。
3. 否定、条件、例外、比较对象、因果关系、完成状态、责任主体和下一步行动。
4. “可能、预计、倾向、约、大幅、仅”等会改变结论边界或强度的词。
5. 作者的经历、判断、犹豫、情绪和有意保留的个人口气。

不得把“预计”改成“确定”，把“相关”改成“导致”，把“可用”改成“最佳”，或把不同指标概括成含义更宽的“效果更好”。引号内文字、代码块和引用材料默认逐字保留；只有用户明确授权时才编辑。

## 决定改写力度

- **轻改**：修正病句、翻译腔、重复和明显套话；保持句序、段落和大部分用词。正式文本、高风险内容或用户要求“尽量别动”时使用。
- **标准**（默认）：可调整句式、连接方式和段落节奏；保留信息、论证顺序和作者立场。
- **结构重写**：只有用户明确要求“大改、重写、重新组织”时使用；可合并、拆分、重排，但保护清单仍不可破坏。

若用户指定受众、渠道、语气、篇幅、必须保留或避免的词，将它们视为硬约束。需要配置或选择风格时，读取 @references/style-profiles.md。

## 怎么改

先读完整段落，确认目的和主线，再从影响最大的地方开始：

- 把英文句法硬套中文的长句拆开，恢复自然的主语、动作和语序。
- 删除不承载新信息的开场、预告、复述、总结和礼貌包装；承担逻辑、承诺或语气作用的内容要保留。
- 把“赋能、重塑、构建闭环、开启新篇章”等空泛包装落回原文已有的动作、限制或结果；原文没有具体机制时，不自行补造。
- 避免机械的“首先／其次／最后”、连续排比、过度工整的段落、滥用冒号和每段都拔高的结尾。
- 合并完整重复的信息，但不要把“相关”“相近”或“可推断”误判为重复。
- 让长短句自然变化；不要为了显得真人而故意加错别字、口头禅、碎句、夸张情绪或无关个人故事。
- 保留合理的专业术语和技术精度。自然表达不等于幼稚化、口水化或降低信息密度。
- 保留 Markdown 层级、列表、表格、链接和代码结构，除非用户授权重排格式。

默认做最小必要修改。正常、准确、有作者特点的句子可以原样保留；不要为了显示工作量而逐句换同义词。

## 使用参考样本

用户提供样稿时，只提炼可复用特征：句长、段落密度、正式程度、叙述视角、论证节奏、幽默浓度和术语习惯。不要复制样稿的事实、案例、独特比喻、标题、金句或强识别性表达。

用户要求模仿具体在世作者时，不复制其可识别文风；改为确认并采用高层特征，例如“短句、克制、数据优先、少形容词”。

## 关于 AI 检测

不要把文字判定为 AI 或人类创作，也不要输出“AI 率”。检测器分数不是可靠的质量指标。

如果用户要求“保证过检测”或“绕过检测器”，说明无法保证，也不以操纵检测结果为目标；仍可完成以可读性、原创表达、事实保真和目标受众为标准的正常编辑。不得为了降低检测分数而加入错误、乱码、不自然同义词、虚构经历或刻意破坏语法。

## 输出

默认只输出改写后的完整正文，不附冗长诊断、自评分或“已为你优化”等套话。

用户要求解释时，按以下顺序输出：

1. 改写稿。
2. 3–6 条关键修改，说明具体改善了什么。
3. 仅在存在事实歧义、缺失来源或保护冲突时给出简短风险提示。

只审不改时，每条包含“片段—问题—修改方向”，并区分明确问题与主观取舍。没有明显问题就直说，不为凑数挑错。

## 交付前核对

- 保护清单中的每一项仍在，且对应关系未变。
- 没有新增事实、证据、引用、经历、承诺或结论。
- 否定、条件、范围、不确定性和判断强度没有漂移。
- 语气符合受众与渠道，没有变成客服腔、公告腔、营销号或刻意口语。
- 改动带来明确收益；无收益的同义替换已撤销。
- 读起来顺畅，但没有牺牲准确性或作者辨识度。
