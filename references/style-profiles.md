# 风格配置

仅在用户指定风格、渠道或需要从参考样本提炼风格时读取本文件。不要把配置项机械地全部展示给用户；从自然语言中推断即可。

## 可配置维度

| 维度 | 可选方向 | 默认 |
|---|---|---|
| 改写力度 | 轻改 / 标准 / 结构重写 | 标准 |
| 正式程度 | 口语 / 自然 / 商务 / 正式 | 沿用原文 |
| 信息密度 | 精简 / 平衡 / 详细 | 保持原文 |
| 判断强度 | 克制 / 原样 / 鲜明 | 原样 |
| 结构 | 原位 / 保留段落 / 可重排 | 保留段落 |
| 作者声音 | 保留原声 / 中性 / 参考样本特征 | 保留原声 |
| 中文变体 | 保持原文 / 简体 / 繁体 | 保持原文 |
| 输出 | 仅改稿 / 改稿加说明 / 只审不改 | 仅改稿 |

硬约束优先级：用户本轮明确要求 > 项目规范与术语表 > 原文稳定特征 > 本技能默认值。

## 常用组合

### 干净专业

适合产品分析、报告、技术文章和公开说明。用词准确、少口号，段落围绕问题推进。可以有判断，但先给依据，不主动热情化。

### 自然商务

适合邮件、客户回复、周报和内部沟通。礼貌但不堆敬语；尽早说明进展、阻塞和下一步；保留责任主体与时间承诺。

### 作者型长文

适合博客、专栏、newsletter。保留个人立场、节奏和有意重复；减少模板转场和统一句式。不要把不同段落磨成同一种声调。

### 自然口语

适合聊天、社群消息和口播。短句、直接、有停顿，但不强行加网络词、语气词、错别字或“说实话”等伪真人标记。

### 克制营销

适合产品介绍和活动文案。保留可核查卖点、条件和承诺；删除无信息口号，降低无依据的最高级。吸引力来自具体价值，不来自夸张。

### 社媒精简

适合微博、小红书、朋友圈等短内容。开头尽快进入主题，段落便于扫读；标题和钩子不得夸大或制造原文没有的冲突。
